# Roadmap

Onde o Axolote Suite está e para onde vai. As prioridades mudam conforme o que a comunidade pede, então [abra uma issue](https://github.com/axolotesuite/axolotesuite/issues/new/choose) se quiser votar ou sugerir algo.

## ✅ Pronto (v1.3.0)

- Conversor Fácil Universal com destinos inteligentes por tipo de arquivo
- Estúdio de Fotos com preview ao vivo, filtros, recorte e compressão
- Editor de Vídeo com linha do tempo, velocidade, formatos de tela e CRF
- Estúdio de Áudio (conversão, extração de vídeo e bitrate)
- Central de PDF (unir, dividir e metadados)
- ZIP com proteção anti Zip-Slip
- Cores & Senhas (HEX/RGB/HSL/CMYK, paleta de foto, senhas e UUID v4)
- Produtividade (notas, tarefas, calculadora, organizador e renomeação em lote)
- Instalador com download automático do FFmpeg e desinstalador

## 🔨 Em andamento

- [ ] CI no GitHub Actions gerando o `.exe` de cada release automaticamente
- [ ] Arquivo `SHA256SUMS.txt` anexado a todo lançamento
- [ ] Mais testes nos `service.rs` de cada módulo

## 🔭 Próximos passos

- [ ] Assinatura de código do executável (para acabar com o aviso do SmartScreen)
- [ ] Versão portátil em `.zip`, sem instalador
- [ ] Instalador `.msi`
- [ ] Interface em inglês e espanhol
- [ ] Conversão em lote no Conversor Fácil (vários arquivos de uma vez)
- [ ] Remoção de fundo de imagem 100% offline
- [ ] Atualização automática dentro do app
