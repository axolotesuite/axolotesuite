# Identidade visual do Axolote Suite

Esta pasta contém a proposta inicial de identidade visual do projeto.

- `banner.svg`: banner horizontal para a página principal.
- `logo.svg`: logotipo horizontal.
- `icon.svg`: ícone quadrado do mascote.

## Direção visual

Paleta principal: roxo, branco e tons escuros. O mascote é uma representação estilizada de um axolote.

Os arquivos são vetoriais e podem ser redimensionados sem perda de qualidade.
