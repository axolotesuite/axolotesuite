# Documentação dos módulos

Registre aqui, para cada módulo:

- Objetivo.
- Arquivos principais.
- Entradas e saídas.
- Dependências externas.
- Formatos suportados.
- Tratamento de erros.
- Testes realizados.
- Limitações conhecidas.

O estado de cada módulo deve distinguir claramente planejado, implementado, testado e publicado.
