# Segurança

Esta pasta reúne revisões de segurança, decisões e riscos conhecidos.

Cada revisão deve registrar:

- Área analisada.
- Arquivos e componentes envolvidos.
- Riscos identificados.
- Correções realizadas.
- Riscos restantes.
- Evidências e testes executados.

Não declarar que o projeto é seguro apenas por funcionar offline.
