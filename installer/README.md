# Instalador

Esta pasta é reservada aos arquivos do instalador do Windows.

Inclua aqui apenas scripts, configurações e recursos necessários à instalação e desinstalação. Binários gerados devem ficar fora do controle de versão, salvo decisão explícita de publicação em Releases.

Documente os componentes baixados, URLs oficiais, hashes de verificação e licenças.
